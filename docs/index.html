Ace

A voice-first study companion that talks you through what you're learning instead of quizzing you at it. Point it at a photo of your notes and it reads them, asks you questions, and matches how you sound — calmer when you're stressed, quicker when you're flying.

This page is a preview, not the app. Ten screens, including first-open onboarding, settings and the crisis-support surface — Ace is a native iOS app, so it can't run in a browser — nothing on a web page can. What you can tap through below is built from Ace's actual design tokens and copy, pulled straight from the source in this repo, so the colours, spacing, type and words are exactly what the app renders. To run the real thing you need Xcode and an iPhone or simulator — see the README.

What it does

  • Reads your notes. Photograph a page, a slide, a worksheet. Vision pulls the text out and Ace cleans it up.
  • Asks before it tells. The tutor is Socratic by default — it wants your answer first, and only explains after you've had a go.
  • Matches how you sound. Pace and warmth ease toward how you seem to be doing. It mirrors; it never imitates you.
  • Remembers for you. A real SM-2 scheduler decides when each card comes back — and now tells you. One reminder a day at most, only when something is actually due, never a streak countdown or a red badge.
  • Sits with you. A body-double mode with a goal, ambient sound, and the occasional quiet check-in.
  • Works with no key at all. Demo Mode runs entirely on-device and is the floor everything falls back to — no key, no network, a dropped socket all land in an app that still works.
  • Knows when to stop being a game. Say you're exhausted and the XP goes quiet. Say something that matters more and the whole game layer gets out of the way.

Verification

Ace was built on a machine with no Xcode — no simulator, no iOS SDK, no XCTest. That constraint shaped the whole project. Everything below runs from the command line.

The palette

Dark-only, by decision rather than default. Every value below is the exact constant the app renders, and every one is covered by a WCAG contrast check that runs in CI — because on a machine with no simulator, “is this readable” has to be a number rather than an opinion.
